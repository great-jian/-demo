# 龙骨余烬 · 太刀 × 巨戟龙

可在浏览器直接运行的 2D 横版战斗 Demo。双击 `index.html` 即可开始，无需安装依赖、无需联网。游戏内「招式手册」包含完整动作说明。

| 按键 | 操作 |
| --- | --- |
| A / D | 左右移动 |
| 空格 / W | 跳跃 |
| Shift | 回避，消耗耐力；突刺落空也可取消 |
| J / K | 轻 / 重三连，支持混合输入和预输入 |
| J + K | 同时按下后撤斩，命中大量回气 |
| U | 点按气刃Ⅰ / Ⅱ / Ⅲ / 大回旋，消耗练气 |
| 长按 U | 蓄力约 1.1 秒，松开释放大回旋，消耗 40 练气 |
| I | 普攻后派生看破；躲过攻击且回斩命中升刃、回满练气 |
| O → O / U | 特殊纳刀 → 居合。出刀后 0.03–0.25 秒接住攻击免伤升刃 |
| H | 非红刃集中弱点刺击，消耗 20 练气；红刃气刃突刺 |
| 红刃 H → U → U | 命中突刺腾空 → 空中登龙 → 落地 1.3 秒内无双斩，最终降至白刃 |
| P / Escape | 暂停 |
| R | 以当前模式重新开始 |
| F | 全屏 |

白刃 / 黄刃 / 红刃伤害倍率为 1 / 1.35 / 1.85。初始白刃，普通攻击积攒练气。气刃大回旋、成功看破、精准居合、集中破坏伤口均可升刃。红刃轻攻击变为更快的赤刃斩。居合失败后摇较长，可以长按 U 蓄力取消。

巨戟龙具有前爪下砸、横扫、短前摇甩尾、黑油喷射、龙车五种攻击；半血进入液化阶段，下砸变双段，油池会定时引燃爆炸。地面显示范围及前摇时间。连续输出可制造爪部伤口，集中刺击命中伤口升刃。身体碰撞采用可游玩的简化判定，爪部是主要目标；体长与猎人身高约为 20:1。

练习模式不扣生命，但保留受击硬直和反击判定。窗口失焦自动暂停。音效默认关闭，可点击页面右上角开启。

这是按需求简化的同人玩法原型，不是官方招式帧数据复刻。巨戟龙美术从提供的参考图提取，猎人、长刀、背景与特效由 Canvas 绘制；另一张猎人参考图保存在 assets 目录。

如浏览器限制直接打开文件，可在本目录执行 `python3 -m http.server 8765`，访问 `http://localhost:8765`。
